# DEPRECATED

This Playwright bot POC has been superseded by Vexa integration in Phase 2.

The production meeting bot is now powered by Vexa (see `../vexa-main`).
Vexa handles: browser automation, audio capture, per-speaker transcription, and WebSocket streaming.

To start Vexa:
```
cd ../vexa-main && make lite
```

This directory is kept for reference only. Do not modify or depend on it.
